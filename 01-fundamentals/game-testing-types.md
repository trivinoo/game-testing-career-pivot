# Types of Game Testing

> Game QA is not a single role — there are several specializations.
> Understanding these helps you position your skills and target the right openings.

---

## 🗂️ The Main Types

### 1. Functionality QA (FQA)
**What it is:** Testing that the *game mechanics work* as intended.  
**Focus:** Crashes, game-breaking bugs, physics, AI behavior, UI logic, multiplayer sync.  
**Analogy to software QA:** Closest to classic functional testing.  
**Requires:** Technical aptitude, systematic test execution, strong bug reporting.

---

### 2. Localization QA (LQA) ← *Target role*
**What it is:** Testing that translated content is linguistically correct and culturally appropriate *in context*.  
**Focus:** Grammar, spelling, punctuation, tone, truncation, missing strings, subtitle sync, glossary compliance.  
**Analogy to software QA:** Like UI + content testing, but the "content" is language.  
**Requires:** Native/near-native fluency in target language + English, attention to detail.

> 💡 **This is the role you're targeting.** See [`02-lqa-specifics/`](../02-lqa-specifics/) for deep detail.

---

### 3. Compliance / Certification Testing
**What it is:** Ensuring the game meets platform holder requirements (Sony TRC, Microsoft TCR, Nintendo LOT).  
**Focus:** Age rating enforcement, online safety, accessibility features, content guidelines.  
**Requires:** Knowledge of platform-specific certification requirements.

---

### 4. Audio QA
**What it is:** Testing that all audio assets (VO, SFX, music) play correctly.  
**Focus:** Missing audio, wrong audio, volume levels, clipping, VO not matching subtitles.  
**Often overlaps with:** LQA (subtitle/audio sync) and FQA (trigger logic).

---

### 5. Functionality + Localization Combo (FQA+LQA)
Some projects and studios combine both roles, especially on smaller productions.  
Knowing both makes you more valuable.

---

### 6. Accessibility QA
**What it is:** Testing features for players with disabilities (colorblind modes, subtitles, remappable controls).  
**Growing in importance** — increasingly required by law in some regions (EU Accessibility Act 2025).

---

### 7. Performance / Technical QA
**What it is:** Testing frame rate, load times, memory usage.  
**Requires:** Closer to engineering, often uses profiling tools.

```
      ↓

      ↓
LQA Regression
      ↓
Cert / Gold Master
      ↓
Release
```
