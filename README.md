# 🎮 Game QA / LQA Study Repository

> **Career pivot:** Software QA → Game Localization QA (LQA)  
> Tailored for the **Keywords Studios LQA Tester** role (Brazilian/European Portuguese)

## 🗺️ Who this is for

This repo is built for someone with a solid **software QA background** who wants to break into the **game testing / LQA** industry. It maps your existing skills to new game-specific ones and fills the gaps with targeted study material.

## ⚡ Your Transferable Skills (Software QA → Game LQA)

| Software QA Skill | How it maps to Game LQA |
|---|---|
| Writing clear bug reports | Core daily task — same structure, new domain |
| Regression testing | Re-testing fixed linguistic bugs across builds |
| Test case design | LQA test plans, linguistic checklists |
| Attention to detail | Spotting typos, grammar errors, truncated text |
| Agile/JIRA workflow | Same tools (or equivalents: DevTrack, Mantis, internal) |
| Working with specs/requirements | Working with style guides, glossaries, translation briefs |
| Reproducibility mindset | Exact steps to reproduce in-game: chapter, scene, dialogue line |
